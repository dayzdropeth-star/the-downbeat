"The Downbeat" — an original poem about agency: a conductor who makes music without playing a note, and learns the edge of what is his when the music goes on without him.

## Run it

```sh
python3 main.py
```

This writes the poem to `entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
